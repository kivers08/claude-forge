- memory-v2 record foundation (D28, unit 1): `plugins/forge/hooks/lib/memory.js`, a stdlib-only library to read/write per-agent memory records as markdown-with-frontmatter under `.claude/agent-memory/<plugin>-<agent>/`, with per-scope read isolation (D4), a strict `<plugin>-<scope>` charset that blocks path-traversal outside the memory root, one-level nested-map / array serialization for preserved `extra` fields, full §3.2 schema defaulting on write, a `supersedes` upsert that archives — never destroys — the old record, and a secret-redaction scrubber (PEM/API-key/token/`*_SECRET=` forms) run before every write that stamps a redaction caveat into any record it touched.
- `scripts/migrate-agent-memory.js`: a SAFE, additive, idempotent migration seed that stamps the memory-v2 schema onto existing `.claude/agent-memory/**` records while preserving their content and prior frontmatter and routing every write through the same secret scrubber; MEMORY.md indexes are left untouched. Per D28.2, memory migration is EXPLICIT (run deliberately at adoption), so this seed is NOT run as part of unit 1 — it does not auto-migrate this repo. The full archive-model adoption migration (move pristine originals to `_pre-migration/<scope>/`, never delete, human-invoked) is deferred to unit 8.
