# Labels

Every hub entry carries 1 to 3 of these. Only listed labels are allowed (the
forge hub script refuses others). Format: `- <label>: <meaning>`.

## Standard (every repo, opusjevos D-BO)

- merge: branches, pull requests, merging, merge rules
- ci: automated checks, workflows, test runs in CI
- tests: writing or changing tests, test results
- deploy: releasing, hosting, environment setup
- config: settings files, plugin and tool configuration
- security: secrets, access, permissions, guards
- data: stored records, schemas, migrations, imports
- ui: screens, forms, what a user sees
- docs: documentation, plans, notes
- compliance: legal and regulatory rules
- customer-messaging: anything sent to customers (texts, email, wording)
- performance: speed, cost, usage limits
